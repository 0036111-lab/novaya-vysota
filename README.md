# Новая высота

Статический MVP сайта платформы экстремального спорта.

Версия 3 добавляет культурно-редакционную линию «Движение передаётся»: парные истории поколений, красные скобки, чёрно-белую документальную основу и рубрики «Семейная линия», «Первый спот», «Семейная сессия». Базовая архитектура платформы — спортсмены, инфраструктура, события и партнёры — сохранена.

## Локальный просмотр

Откройте `dist/index.html` в браузере или запустите локальный статический сервер из каталога проекта.

## Перед публичным запуском

1. Повторно приложить портфолио Веры и заменить поля со статусом «требует сверки» только подтверждёнными формулировками.
2. Согласовать права на фотографии, логотипы, имя и спортивные результаты.
3. Добавить подтверждённые контакты проекта.
4. Подключить форму к почте, CRM или Telegram-боту.
5. Создать Telegram-канал, закрепить публичный адрес и заменить на сайте статус подготовки ссылкой.
6. Подключить аналитику, политику обработки данных и юридические реквизиты оператора формы.

## Структура

- `dist/index.html` — основной сайт.
- `dist/media-kit.html` — веб-медиакит.
- `dist/styles.css` — визуальная система и адаптивная вёрстка.
- `dist/app.js` — мобильное меню, форма и локальное сохранение заявки.
- `.openai/hosting.json` — настройки публикации Sites.
